# dufs LazyCat community package

Upstream https://github.com/sigoden/dufs. Official-store source mcloud.mg.app.dufs. Package community.lazycat.app.dufs,0.47.0; minOS1.6.0 for service run_as1000:1000 directory owner mapping; linux/amd64 mirror delivery, community store only. Intended category: Network / File Share38.

Single HTTP5000 container, no database. LazyCat entry protection plus stable random internal Basic credentials injected server-side. Granted app members share read/write access to /lzcapp/var/files; not per-user storage. Deleting affects other members, so only grant access to trusted people. Export/backup before uninstalling.

Enable upload/delete/search/archive/hash individually. Do NOT enable allow-all or allow-symlink. No public anonymous paths or extra protocol ports. No smoke or file interception. Runtime startup, auth injection, upload/download, delete, archives, WebDAV compatibility and persistence have not been verified on a real device.
